# 人臉辨識考勤系統

這是影像處理課程的期末專題。我們希望探索如何利用人臉辨識輔助點名，減少傳統逐一點名所需的時間。專題以學生出缺勤及公司考勤作為應用情境，實作一個透過攝影機辨識人員並記錄到達時間的程式。

## 系統如何運作

程式先讀取三組人臉照片，將影像轉為灰階，再使用 OpenCV 的 Haar Cascade 偵測照片中的人臉。擷取人臉區域後，以 LBPH 方法訓練辨識模型，並將模型儲存為 `face.yml`。

完成訓練後，程式開啟電腦攝影機，持續偵測畫面中的人臉。辨識到已登錄的人員時，畫面會顯示對應名稱；程式也會將該人員標記為「已到」，記錄第一次辨識到的日期與時間。關閉攝影機畫面後，終端機會列出各人員的最終狀態。

## 專題展示

本專題以三組人臉資料進行訓練與展示。簡報呈現了單人及多人進入鏡頭時的辨識畫面，也記錄了開發過程中遇到的問題，例如 OpenCV 畫面無法正常顯示中文，以及不同人臉被誤判為同一人的情況。

## 使用技術

- Python、NumPy
- OpenCV
- Haar Cascade 人臉偵測
- LBPH 人臉辨識

## 儲存庫檔案

- `finalproject.py`：訓練模型、開啟攝影機、人臉辨識與點名紀錄的程式。
- `haarcascade_frontalface_default.xml`：人臉偵測所需的模型檔。

為保護參與者的個人資料，公開儲存庫未提供訓練用的人臉照片及訓練後的 `face.yml`。因此，僅下載這個儲存庫的檔案，無法直接執行完整辨識流程。
